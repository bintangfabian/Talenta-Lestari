╔══════════════════════════════════════════════════════════════╗
║                    CARA MENJALANKAN                          ║
╚══════════════════════════════════════════════════════════════╝

1. Install dependencies:
   $ composer install
   $ npm install

2. Setup database:
   $ php artisan migrate --seed

3. Jalankan aplikasi (2 terminal):
   Terminal 1: $ php artisan serve
   Terminal 2: $ npm run dev

4. Akses browser:
   http://localhost:8000
